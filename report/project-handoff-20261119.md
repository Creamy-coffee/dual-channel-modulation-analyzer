## 1. 项目是什么

这是一个由 FPGA 和 Linux 屏协同完成的双通道信号采集与分析仪。硬件采集端使用 AD9238 双通道 12 bit ADC，以 65 MSPS 同步采样；Artix-7 XC7A35T 完成采集、触发、抽取、FFT、DDC、锁相和帧打包；RK3506 Linux 屏端负责串口接收、界面显示、部分调制分析与比特判决。

系统的主链路为：

```text
模拟输入
  -> AD9238 双通道同步采样（12 bit，65 MSPS）
  -> FPGA 采样缓存/触发/抽取/FFT/DDC/锁相/谐波计算
  -> AA5/AB5 UART，2 Mbaud，带 CRC 的 V32 帧
  -> RK3506 接收和解析
  -> 7 英寸屏幕：示波器、频谱、锁相、重建、调制、系统、图片
```

注意：65 MSPS 是 ADC 采样率，不等于屏端逐点连续接收速率。当前 UART 是主要系统带宽瓶颈，屏端收到的是独立分析帧，不能把相邻 RAW 帧当作连续采样拼接。

## 3. 当前已部署/较稳定的能力

### 3.1 基础示波器

- 双通道同步时域显示。
- 时基、电压档位、边沿触发、单次、暂停、历史缓冲等入口已存在。
- 自动示波按钮已按用户需求改为：自动选择当前触发通道，并尽量让波形约占可视区域 80% 高度、约显示 10 个周期。
- 自动状态会显示 `自动 CH1` 或 `自动 CH2`，避免不知道自动调整的是哪一路。
- 通道测量包括峰峰值、最大/最小值、均方根、均值、周期、频率、占空比、上升时间等；其中占空比仅在检测到可靠高低平台时有效，正弦波不显示伪占空比。

### 3.2 频谱与谐波

- FPGA 侧是 4096 点共享 FFT；屏端 RAW 频谱也有 1024 点显示路径。两者用途不同，不能将屏端绘图点数误说为 FPGA FFT 点数。
- 频谱页常开显示谱线。
- 谐波/THD 只能在“存在且稳定的单一基波”时有物理意义。针对多音、宽带噪声、未知调制波，不能强行给出 H1-H5 和 THD。
- 最新 UI 已加入谐波自动跟随：进入频谱页后，稳定检测到基频才发送谐波计算配置；无稳定基频时显示等待状态，离开频谱页后停止谐波捕获，避免给出过期或伪结果。

### 3.3 锁相

- FPGA 用同一 NCO 参考产生正交 sin/cos。
- 两通道分别与参考 sin/cos 相乘并低通/积分得到 I、Q；相位为 `atan2(Q, I)`，两通道相减得到相位差。
- 锁相不是“寻找乘法最大的单个数字”，而是取一段时间内同相分量 I 和正交分量 Q 的平均向量。
- 无可靠激励、相位波动超限或信号过弱时，应显示无效状态，不保留旧读数。

### 3.4 调制分析

- AM：包络/调制度显示；已有指定条件下的实测记录，例如 2 MHz 载波、1 kHz 调制、深度 50% 时屏显约 50.0%。
- OOK：基于包络高低阈值、滞回、符号中心积分判决；不确定样点用 `?`，不强猜比特。
- 2FSK：从瞬时频偏的双状态判决；要人工或算法给出合适符号率。
- BPSK：可做符号同步、恢复符号点，并支持历史实采 PN7 闭环记录。
- QPSK：本轮屏端代码已补“恢复后的符号点”显示入口。只有同步锁定后才能画四象限符号点；不能拿未同步的原始 I/Q 散点冒充星座图。

### 3.5 自动识别边界

- 当前 AUTO 仍不是商用矢量信号分析仪级别的未知信号完整制式识别器。
- 对单路未知单音 FM/PM，不能仅根据一个载波波形从物理上唯一确定其来自 FM 还是 PM；二者可以构造出相同瞬时相位轨迹。
- 可靠做法是：保留 `FM/PM ?` 的诚实状态，或在 CH2 同时输入真实调制参考信号后比较“频偏与参考”或“相偏与参考”的对应关系。
- 数字制式 AUTO 仍需要进一步用实采 I/Q、不同符号率和不同信噪比做验收。当前不能宣称 3FSK/4FSK、ASK、PSK 都可自动准确识别。

### B. 频谱页谐波自动跟随

文件：`candidate/src/ui.c`

- `s_hrm_auto`、`s_hrm_auto_ready` 控制自动模式。
- `hrm_auto_update()` 选择频谱页的当前通道，从稳定频率估计中取基频并发送 `v32_cmd_harmonic()`。
- 连续若干帧稳定才开启谐波计算。
- 无基频显示“等待稳定基频”，退出频谱页关闭谐波任务。

验证过的现象：干净 5 MHz 正弦下 H1 约 0 dBc，其余谐波和 THD 显示噪声下限，符合干净单音的预期。仍需对方波及含谐波信号再做实测截图。

### C. BPSK/QPSK 星座图

文件：`candidate/src/ui.c`、`candidate/src/bpsk_decoder.c`

- 调制页在 BPSK/QPSK 下调用符号同步/恢复路径。
- 只有 `locked` 后展示 `sym_i/sym_q` 恢复符号点。
- BPSK 用两点星座，QPSK 用四象限星座；无锁定时明确显示“等待符号同步”。
- 历史 QPSK 原始数据回放显示：在 2000 Bd 候选设置下可获得锁定；这只能证明软件恢复链可运行，不能替代发生器—ADC—FPGA—屏幕整机误码率验收。

### UART 与采样深度的真实限制

- ADC：65 MSPS × 2 通道，12 bit。
- UART：2 Mbaud，8N1，理论有效载荷约 200 kB/s。
- RAW 波形帧约 4140 B，1024 点；4096 原始点帧回传也远低于 ADC 持续输出速率。
- FIFO 只能缓冲突发和时钟域差异，不能解决“持续 65 MSPS 数据量远大于 UART 带宽”的基本矛盾。
- 深存储/长时基连续滚动的正确长期方案是 FPGA 端采样写入外部/片上存储，屏端按需分段读取；若硬件允许，后续用高速 USB、以太网、SPI/并行接口替换 UART 数据面。SPI 只有在两端硬件和 DMA 都支持且速率足够时才是改进，不是只改协议就能解决。

## 6. 当前主要问题与优先级

### P0：现场演示可靠性

1. 检查 FPGA AA5/AB5 UART 与屏端 RX/TX/GND 接线。
2. 确保单一接收者占用串口，避免电脑抓包与屏端同时读取同一串口。
3. 检查 2 Mbaud 连续接收、CRC、帧序号是否增长。
4. 开机默认关闭调制 AUTO；只有点击调制分析才启用，避免分析线程使示波器页面卡顿。
5. 准备离线启动脚本，比赛无网络时可启动屏端程序、检查串口、启动发生器测试预设。

### P1：测量可信度

1. 峰峰值、频率、占空比要逐频点、逐量程用独立参考仪器核对。
2. 不要承诺“30 MHz、10 mVpp 的 0.1% 绝对幅度精度”。现有参考示波器自身量程精度和前端噪声不足以证明这个级别。
3. 弱信号下 Vpp 跳变意味着测量不稳定，应直接给出有效性/稳定度状态，不能用估计符号替代真实读数。
4. 上升时间对正弦波和带宽不足时没有意义，应仅在符合脉冲边沿条件时显示。

### P1：调制分析

1. FM/PM 手动模式的频偏、相偏标定尚未通过。其载波局部显示必须按合适时基展示“疏密变化”，但不要将视觉效果当成定量准确性的证明。
2. AUTO 对 3FSK/4FSK 曾误判为 AM，对 ASK 未稳定显示，对 PSK 曾显示 FM/PM；应先抓对应 ANA/IQ 原始数据，再建立特征阈值，不能仅靠界面文字修补。
3. QPSK 的恢复符号点要实屏验证；QPSK 的 bit 映射、前导、极性/相位旋转和 BER 尚未验收。

### P2：产品化

- 探头倍率、通道校准记录、开机自检、输入过压保护主要涉及软硬件共同完善。
- History 适合暂停后回看、对比、导出，不应替代实时显示。
- CSV/VOFA 只保留一种主机导出方式即可。建议保留 CSV/串口二进制抓包作为可追溯测试手段；实时绘图仅作为辅助，不替代屏端。

## 8. 最小化演示流程

1. 启动 FPGA 正式位流 `fpga_4096ca03.bit`，确认 UART 有帧。
2. Linux 屏启动后默认在示波器页，调制分析保持关闭。

## 10. 关键术语速查

- **抽取 decimation**：低通后每隔 N 个样点保留一个，降低有效采样率、扩大可观察时间范围，同时降低奈奎斯特带宽。
- **FFT/DFT**：把一段时域采样转换为各个频率分量的幅度和相位；4096 点 FFT 的频率间隔约为 `Fs_eff / 4096`。
- **DDC**：用数字 NCO 与载波混频，将感兴趣的载波搬到低频/基带，再滤波抽取。
- **I/Q**：与相差 90°的两路参考相乘得到同相 I、正交 Q；向量幅度与相位分别由 `sqrt(I^2+Q^2)`、`atan2(Q,I)` 求得。
- **锁相/Lock-in**：在已知参考频率附近做窄带相关积分，提升相干分量、抑制非同步噪声，并从 I/Q 得出幅相。
- **AM 包络**：复基带模长或局部峰值跟踪得到的慢变化振幅轮廓；调制度常由 `(Amax-Amin)/(Amax+Amin)` 估计。
- **星座图**：符号同步、载波恢复后的 I/Q 符号点分布。原始 I/Q 轨迹不等于星座图。

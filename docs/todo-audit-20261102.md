## 二、逐条明细

### 1　QPSK：主机侧做过，屏端没做

- **历史主机侧结果**：4 段真实 IQ，CRC 全对 2917 帧、帧内缺口 0；留出符号
  62712 个、符号错误 **0**；EVM 0.07740–0.07789。覆盖 500 Bd 与 2000 Bd，
  ADC 通道 0 与 1 都有。
  证据：`firmware/reports/display_clarity_20261028/qpsk_history_audit.json`
  （`pass: true`）。
- **但 2026-10-31 那次是重核传输证据，没有重跑符号恢复算法**；所以这 62712 个
  符号是历史离线结果，不是当日新测。
- **屏端仍未移植**：`src/ui.c:3266` 原文
  `QPSK RF/host recovery was tested on 2026-10-22. The screen exposes its existing IQ observation; host symbol recovery is not ported here.`
  屏上 QPSK 只画 I/Q 轨迹。

**不能写成「QPSK 已完成」**，也不能由 BPSK 的实机闭环推及。

### 2　BPSK：实机资格记录已经有了

2026-10-27 实机（发生器 CH2 → ADC CH0 → 屏端 CH1，1 MHz 载波、1000 bit/s、PN7、
0°/180°，屏端提交 `d182c3e`）：

- 372 个 BPSK ANA 帧 CRC 全对，坏候选 0，帧号 10665–11036 连续，95232 样点覆盖 6.001081 s
- ARM 端导出 **5747 bit**，本机同核心 CLI 逐字节一致
- 训练之后 **5460 次检查、错误 0**，零擦除，PN7 已锁定
- 独立于解码器的 bit 审计：PRBS7 递推 5740 次零违例（允许全局极性）、
  周期 127 比较 5620 次零错、首 127 个七位状态互不相同
- GUI 附件审计：**24.2463 s** 合格连续片段、25 个快照，末次参考检查 24702 次、
  零错零擦除；EVM 0.0260–0.0481；原始片段本机粗 CFO 144.65 Hz

证据：`firmware/reports/BPSK真实bit闭环结果_20261027.md`、
`firmware/reports/bpsk_bits_hold_20261027_102339/`。

**原先写的「实机帧 EVM 0.060 / 状态待判决」来自更早一次未获符号同步的运行**
（对应仓库截图 `11-mod-bpsk.png`）。那张图作为「未同步时不给假星座」的证据仍然成立，
但它不是 BPSK 的最终状态。

仍未闭环的部分，照实保留：BPSK 历史 3 次擦除定位在参考训练之前／期间，后续多段
同读者记录未复现，根因未查清；180° 极性歧义需外部参考；这些都不是通用 BER。

### 3　图片页：屏上走完了，独立核验没做

- `image_rf_ook_20261027_164947/window_result.json`：
  `screen_completed: true`、**`physical_image_accepted: false`**、
  `requires_independent_capture_audit: true`
- 2026-10-29 补测（32×32 OOK、4 包、progress 100、设置已恢复）在 `acceptance.md` 里
  自己写明：只证明发送端与 VISA 控制的互斥隔离，**不代表屏端收到图或 CRC 通过**
- 已通过的是：OOK/2FSK/BPSK 合成回环 + ADB 逐像素显示

所以「真实载波下整图独立验收」仍然缺位。

### 4　七页绘制帧率：探针在，数据没有

`src/main.c:340` 起有 `--fps [SEC]`：先按正常节奏跑，再强制每轮重绘，分别报
「实际运行帧率」与「渲染上限」，并把单帧拆成软件渲染 / DRM 翻页两段。
现成的 9.9 FPS 是六页版本（1024 点折线 × 2 通道）的数据，七页版本没测过。

跑一次即可闭环，但需要板子在线：

```bash
./waveform_demo --source uart --view system --fps 15
```

### 5　本次重建产物上板

`docs/build-verify-20261102.md` 里那次干净重建，只做到「构建侧可复现」：
资源 20294 LUT / 13111 FF / 80 DSP / 36 BRAM、WNS +0.172 ns / WHS +0.010 ns、
DRC 138 条全 Warning 无 Error，与历史逐项一致。bit 生成了（2,192,115 B，
SHA256 `0a64f12e…`），但**没有下载到板子上跑过功能**。

另需注意：bit 头里 Vivado 写入了构建时间
（`daq_top;UserID=0XFFFFFFFF;Version=2018.3 7a35tfgg484 2026/11/02 17:29:09`），
逐字节复现历史 bit 不可能，判据应落在 USR_ACCESS + 时序资源 + DRC + 上板。

### 6　正式工具链重编

全盘检索 `gcc-arm-10.3` / `arm-none-linux-gnueabihf-10.3` / `10.3-2021.07`：
没有工具链目录，也没有任何构建记录。本次重建用的是 SDK 自带 ARM GCC 7.3.1，
产物 ABI 正确（`ELF32 / ARM / v7-A / VFPv4 / Tag_ABI_VFP_args: VFP registers`，
链接 2,258,844 B），但编译器不是发布用的那一个。

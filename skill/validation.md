# 验证案例

## 2026-11-12，OOK 图片接收

UTG2062X CH2 接 FPGA ADC CH0，对应 Linux 界面 CH1。源端输出 1 MHz 载波、OOK 1000 Bd。图像 32×64 单色，分 8 包。发送器操作成功时，接收端选 CH2 仍为 0 包。保持同一图像和制式，改选 CH1 后重发，实屏 8/8 包、整图 CRC32 32f70bed、包 CRC 错误 0。记录 16 个重复包、21 个 DSP gap。实屏和原图的 2048 个像素块中心逐点比对，差异 0。

发送端操作完成只确认发生器侧控制流程。接收端必须独立核对通道与业务结果。这次验证覆盖上述接线、速率和图像，不能作为任意码型的 BER 测量。

fixtures/smiley_payload.hex 保存去掉 PBM 文件头后的 256 个有效字节。自检用记录的 CRC32 做独立比对，再翻转一位确认脚本拒绝。自检另外使用标准文本向量 123456789，其 CRC32 为 cbf43926，以验证换载荷仍可运行。

# 从零定位 UART 到界面的故障

1. 记录发送和接收版本、波特率、电平、交叉接线、共地、设备名和应用通道映射。串口只保留一个读者。
2. 用同一时间窗统计发送事件、接收原始字节、有效帧、CRC 错误和帧序间隔。烧录瞬间有变化时，分别记录配置前、配置完成、稳态。
3. 原始字节始终为 0 时，验证源端是否实际发送、接收脚是否有活动以及设备节点是否对应。原始字节增长但有效帧为 0 时，核对帧头、长度、字节序、CRC 和同步。
4. 有效帧增长而界面停滞时，核对回显通道、制式、速率、配置序号与结果时间戳。回显没有请求 ID 时，仅能确认参数匹配。
5. 每轮只改一个因素。保存修改前后计数、参考输入和最终输出。图像以完整包数、整图 CRC 和实屏比对验收。

## 可复制的协作提示词

> 设备、版本、接线和协议为 <填写>。同一时间窗的发送事件、原始字节、有效帧、CRC 和业务输出为 <填写>。预期输出为 <填写>。请把结论分成观察、假设和待验证，每个判断对应一条原始证据。给出能区分首要两项假设的单变量实验，并写明成功与失败各如何判断。

无可对齐的日志时，先按第 2 步收集证据。只有最终画面时，无法由该流程唯一确定故障层。
